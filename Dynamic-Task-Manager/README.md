# Dynamic Task Manager & Productivity Tracker

A responsive task management web application that helps users organize daily activities, manage priorities, and track their productivity.

## Features

- **Add Tasks:** Create new tasks with a title, category, and due date.
- **Edit Tasks:** Update existing task details.
- **Delete Tasks:** Remove tasks when they are no longer needed.
- **Mark as Complete:** Mark tasks as completed or active.
- **Category Management:** Organize tasks into Work, Personal, and Study categories.
- **Task Filters:** Filter tasks by All, Active, and Completed status.
- **Search Tasks:** Find tasks quickly using the search feature.
- **Dashboard Statistics:** View total, active, and completed task counts.
- **Local Storage:** Automatically save tasks in the browser so they remain available after refreshing the page.
- **Responsive Design:** Works on desktop, tablet, and mobile screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run the Project

1. Download or clone the repository.
2. Open the `Dynamic-Task-Manager` folder.
3. Open `index.html` in your web browser.
4. Start adding and managing your tasks.
