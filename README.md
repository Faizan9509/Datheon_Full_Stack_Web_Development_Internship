# Personal Developer Portfolio

A responsive personal portfolio website showcasing my profile, technical skills, projects, education, and experience.

## About Me

I am Faizan , a BSc IT student interested in software development, frontend development, and cloud computing. I enjoy learning new technologies and building practical projects.

## Features

- Personal introduction and profile photo
- About Me section
- Technical skills showcase
- Experience section
- Project portfolio
- Education details
- Contact and social media links
- Dark and light theme toggle
- Responsive navigation menu
- Downloadable resume

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
Portfolio/
├── index.html
├── README.md
├── resume.pdf
├── css/
│   └── style.css
├── images/
│   └── profile.png
└── js/
    └── script.js
```

## Run Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
